## Socioboard

A self-hosted Socioboard stack, ready to deploy with Stacker.

### What's included

- **Socioboard** (socioboard)
- **Socioboard Mysql** (socioboard-mysql)
- **Socioboard Mongo** (socioboard-mongo)

### Docker images

- `sintelli/socioboard-web:latest`
- `sintelli/socioboard:latest`
- `mysql:8.4`
- `mongo:6`

### Quick start

```bash
stacker install socioboard
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
