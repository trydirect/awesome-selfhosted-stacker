## Langflow

A self-hosted Langflow stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `langflowai/langflow:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install langflow
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
