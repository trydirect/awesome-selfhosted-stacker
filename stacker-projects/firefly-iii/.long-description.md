## Firefly Iii

A self-hosted Firefly Iii stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `fireflyiii/core:version-6.1.24`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install firefly-iii
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
