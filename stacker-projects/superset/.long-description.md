## Superset

A self-hosted Superset stack, ready to deploy with Stacker.

### What's included

- **Superset Db** (superset_db)
- **Redis** (redis)

### Docker images

- `apache/superset:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install superset
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
