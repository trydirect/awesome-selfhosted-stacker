## Pipe Webhook Demo

A self-hosted Pipe Webhook Demo stack, ready to deploy with Stacker.

### What's included

- **Ntfy** (ntfy)

### Docker images

- `caronc/apprise:1.8.0`
- `binwiederhier/ntfy:v2.8`

### Quick start

```bash
stacker install pipe-webhook-demo
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
