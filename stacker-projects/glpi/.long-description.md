## Glpi

A self-hosted Glpi stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `glpi/glpi:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install glpi
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
