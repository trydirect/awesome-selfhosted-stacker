## Vikunja

A self-hosted Vikunja stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `vikunja/vikunja:2`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install vikunja
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
