## Anythingllm

A self-hosted Anythingllm stack, ready to deploy with Stacker.

### Docker images

- `mintplexlabs/anythingllm:1.18.0`

### Quick start

```bash
stacker install anythingllm
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
