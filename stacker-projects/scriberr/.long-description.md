## Scriberr

A self-hosted Scriberr stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/rishikanthc/scriberr:v1.2.0`

### Quick start

```bash
stacker install scriberr
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
