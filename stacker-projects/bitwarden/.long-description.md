## Bitwarden

A self-hosted Bitwarden stack, ready to deploy with Stacker.

### What's included

- **Bitwarden Db** (bitwarden_db)

### Docker images

- `vaultwarden/server:1.32.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install bitwarden
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
