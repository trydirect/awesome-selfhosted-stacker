## Netbird

A self-hosted Netbird stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `netbirdio/management:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install netbird
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
