## Planka

A self-hosted Planka stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `ghcr.io/plankanban/planka:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install planka
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
