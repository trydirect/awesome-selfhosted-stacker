## Limesurvey

A self-hosted Limesurvey stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `acspri/limesurvey:latest`
- `mariadb:11.4`

### Quick start

```bash
stacker install limesurvey
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
