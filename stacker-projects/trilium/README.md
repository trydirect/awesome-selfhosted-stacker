# Trilium

**Self-hosted note-taking application** — hierarchical note organizer with strong encryption.

## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/trilium

# Deploy
stacker deploy --target cloud --key htz-0
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| Trilium | 8081 | Note-taking UI |
