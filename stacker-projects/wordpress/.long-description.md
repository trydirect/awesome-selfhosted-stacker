## Wordpress

A self-hosted Wordpress stack, ready to deploy with Stacker.

### What's included

- **Wordpress Db** (wordpress_db)

### Docker images

- `wordpress:6.6`
- `mysql:8.4.4.0`

### Quick start

```bash
stacker install wordpress
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
