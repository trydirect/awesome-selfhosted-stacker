## Akaunting

A self-hosted Akaunting stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `akaunting/akaunting:3.1.12`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install akaunting
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
