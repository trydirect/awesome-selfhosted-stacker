## Matomo

A self-hosted Matomo stack, ready to deploy with Stacker.

### What's included

- **Matomo Db** (matomo_db)

### Docker images

- `matomo:5.1:5.1`
- `mariadb:11.4.4`

### Quick start

```bash
stacker install matomo
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
