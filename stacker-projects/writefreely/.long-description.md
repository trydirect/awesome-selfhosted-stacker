## Writefreely

A self-hosted Writefreely stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `writeas/writefreely:0.15.0`
- `mysql:8.4.4`

### Quick start

```bash
stacker install writefreely
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
