## Docling Serve

A self-hosted Docling Serve stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/docling-project/docling-serve-cpu:v1.37.0`

### Quick start

```bash
stacker install docling-serve
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
