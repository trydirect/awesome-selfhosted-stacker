## Ghost

A self-hosted Ghost stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `ghost:5-alpine`
- `mysql:8.4.4`

### Quick start

```bash
stacker install ghost
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
