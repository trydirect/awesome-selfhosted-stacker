## Wger

A self-hosted Wger stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `wger/server (pinned version)`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install wger
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
