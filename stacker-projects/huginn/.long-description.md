## Huginn

A self-hosted Huginn stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `ghcr.io/huginn/huginn:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install huginn
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
