## Chatwoot

A self-hosted Chatwoot stack, ready to deploy with Stacker.

### What's included

- **Chatwoot Db** (chatwoot-db)
- **Chatwoot Redis** (chatwoot-redis)

### Docker images

- `chatwoot/chatwoot:develop-ce`
- `pgvector/pgvector:pg16`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install chatwoot
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
