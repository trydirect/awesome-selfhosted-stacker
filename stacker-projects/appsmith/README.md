# Appsmith

**Self-hosted low-code platform** — build internal tools with drag-and-drop UI.

## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/appsmith

# Deploy
stacker deploy --target cloud --key htz-0
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| Appsmith | 80 | Low-code platform UI |
