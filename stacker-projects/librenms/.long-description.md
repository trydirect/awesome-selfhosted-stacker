## Librenms

A self-hosted Librenms stack, ready to deploy with Stacker.

### What's included

- **Db** (db)
- **Redis** (redis)

### Docker images

- `librenms/librenms:24.10.1`
- `mariadb:11.4`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install librenms
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
