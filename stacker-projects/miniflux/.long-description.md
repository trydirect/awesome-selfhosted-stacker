## Miniflux

A self-hosted Miniflux stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `miniflux/miniflux:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install miniflux
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
