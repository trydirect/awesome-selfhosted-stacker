## Paperless Gpt

A self-hosted Paperless Gpt stack, ready to deploy with Stacker.

### What's included

- **Paperless** (paperless)
- **Paperless Db** (paperless_db)
- **Redis** (redis)

### Docker images

- `icereed/paperless-gpt:v0.31.0`
- `ghcr.io/paperless-ngx/paperless-ngx:3.3.1`
- `postgres:18.0-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install paperless-gpt
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
