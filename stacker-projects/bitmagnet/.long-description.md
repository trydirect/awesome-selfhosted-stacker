## Bitmagnet

A self-hosted Bitmagnet stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/bitmagnet-io/bitmagnet:v0.10.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install bitmagnet
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
