## Rocket Chat

A self-hosted Rocket Chat stack, ready to deploy with Stacker.

### What's included

- **Mongo** (mongo)

### Docker images

- `rocket.chat:6.12.2`
- `mongo:7.0.12`

### Quick start

```bash
stacker install rocket-chat
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
