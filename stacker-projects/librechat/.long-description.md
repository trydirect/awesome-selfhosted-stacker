## Librechat

A self-hosted Librechat stack, ready to deploy with Stacker.

### What's included

- **Mongo** (mongo)

### Docker images

- `librechat/librechat:v0.8.8`
- `mongo:7`

### Quick start

```bash
stacker install librechat
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
