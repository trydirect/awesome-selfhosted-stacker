## Lemmy

A self-hosted Lemmy stack, ready to deploy with Stacker.

### What's included

- **Lemmy Db** (lemmy_db)
- **Lemmy Pictrs** (lemmy_pictrs)

### Docker images

- `dessalines/lemmy:0.19.11`
- `postgres:16.4-alpine`
- `asonix/pictrs:latest`

### Quick start

```bash
stacker install lemmy
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
