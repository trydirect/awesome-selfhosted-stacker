## Lychee

A self-hosted Lychee stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `lycheeorg/lychee:v5.0.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install lychee
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
