## Ganymede

A self-hosted Ganymede stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/zibbp/ganymede:latest`
- `postgres:14`

### Quick start

```bash
stacker install ganymede
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
