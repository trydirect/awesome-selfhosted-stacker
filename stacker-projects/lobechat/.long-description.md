## Lobechat

A self-hosted Lobechat stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `lobehub/lobe-chat:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install lobechat
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
