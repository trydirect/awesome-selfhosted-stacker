## Romm

A self-hosted Romm stack, ready to deploy with Stacker.

### What's included

- **Romm Db** (romm-db)

### Docker images

- `rommapp/romm (pinned version)`
- `mariadb:11.4`

### Quick start

```bash
stacker install romm
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
