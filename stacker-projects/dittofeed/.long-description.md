## Dittofeed

A self-hosted Dittofeed stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Clickhouse** (clickhouse)
- **Kafka** (kafka)

### Docker images

- `dittofeed/dittofeed-lite:v0.23.0`
- `postgres:16.4-alpine`
- `clickhouse/clickhouse-server:24.8`
- `apache/kafka:3.8.1`

### Quick start

```bash
stacker install dittofeed
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
