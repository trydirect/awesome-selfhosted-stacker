## Btcpay Server

A self-hosted Btcpay Server stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `btcpayserver/btcpayserver:2.4.5`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install btcpay-server
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
