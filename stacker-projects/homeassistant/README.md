# Home Assistant

**Self-hosted smart home** — home automation platform with 1000+ integrations.

## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/homeassistant

# Deploy
stacker deploy --target cloud --key htz-0
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| Home Assistant | 8123 | Smart home UI |
