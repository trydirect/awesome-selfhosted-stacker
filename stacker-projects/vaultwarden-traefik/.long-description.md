## Vaultwarden Traefik

A self-hosted Vaultwarden Traefik stack, ready to deploy with Stacker.

### Docker images

- `vaultwarden/server:1.32.0`

### Quick start

```bash
stacker install vaultwarden-traefik
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
