## Traccar

A self-hosted Traccar stack, ready to deploy with Stacker.

### Docker images

- `traccar/traccar:latest`

### Quick start

```bash
stacker install traccar
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
