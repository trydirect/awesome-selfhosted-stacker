## Cachet

A self-hosted Cachet stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `cachethq/docker:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install cachet
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
