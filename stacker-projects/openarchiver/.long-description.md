## Openarchiver

A self-hosted Openarchiver stack, ready to deploy with Stacker.

### Docker images

- `logiclabshq/open-archiver:v0.6.2`
- `postgres:17.0-alpine`
- `valkey/valkey:8-alpine`
- `getmeili/meilisearch:v1.38`
- `apache/tika:3.2.2.0-full`

### Quick start

```bash
stacker install openarchiver
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
