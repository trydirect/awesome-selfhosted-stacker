## Jitsi

A self-hosted Jitsi stack, ready to deploy with Stacker.

### What's included

- **Prosody** (prosody)
- **Jicofo** (jicofo)
- **Jvb** (jvb)

### Docker images

- `jitsi/web:unstable`
- `jitsi/prosody:unstable`
- `jitsi/jicofo:unstable`
- `jitsi/jvb:unstable`

### Quick start

```bash
stacker install jitsi
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
