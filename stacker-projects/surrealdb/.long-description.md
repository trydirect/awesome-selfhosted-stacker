## Surrealdb

A self-hosted Surrealdb stack, ready to deploy with Stacker.

### Docker images

- `surrealdb/surrealdb:v2.0.0.0.0`

### Quick start

```bash
stacker install surrealdb
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
