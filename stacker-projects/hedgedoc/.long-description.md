## Hedgedoc

A self-hosted Hedgedoc stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `quay.io/hedgedoc/hedgedoc:1.10.2`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install hedgedoc
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
