## Rybbit

A self-hosted Rybbit stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/rybbit-io/rybbit-client:latest`
- `clickhouse/clickhouse-server:25.4.2`
- `postgres:17.4`
- `redis:7.4-alpine`
- `ghcr.io/rybbit-io/rybbit-backend:latest`

### Quick start

```bash
stacker install rybbit
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
