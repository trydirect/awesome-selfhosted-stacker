## Open Webui

A self-hosted Open Webui stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/open-webui/open-webui:v0.3.32`
- `ollama/ollama:0.3.12`

### Quick start

```bash
stacker install open-webui
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
