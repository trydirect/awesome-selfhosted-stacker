## Zammad

A self-hosted Zammad stack, ready to deploy with Stacker.

### What's included

- **Zammad Websocket** (zammad-websocket)
- **Zammad Worker** (zammad-worker)
- **Postgres** (postgres)
- **Redis** (redis)
- **Memcached** (memcached)

### Docker images

- `zammad/zammad:7.2`
- `zammad/zammad:7.2`
- `zammad/zammad:7.2`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`
- `memcached:1.6-alpine`

### Quick start

```bash
stacker install zammad
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
