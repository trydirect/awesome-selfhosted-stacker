## Readeck

A self-hosted Readeck stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `codeberg.org/readeck/readeck:0.16.2`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install readeck
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
