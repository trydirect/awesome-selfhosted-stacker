## Wordpress Matomo

A self-hosted Wordpress Matomo stack, ready to deploy with Stacker.

### What's included

- **Wp Db** (wp-db)
- **Matomo** (matomo)
- **Matomo Db** (matomo-db)

### Docker images

- `wordpress:6.6`
- `mysql:8.4.4.0`
- `matomo:5.1:5.1`
- `mariadb:11.4`

### Quick start

```bash
stacker install wordpress-matomo
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
