## Mattermost

A self-hosted Mattermost stack, ready to deploy with Stacker.

### What's included

- **Mattermost Db** (mattermost-db)

### Docker images

- `mattermost/mattermost-enterprise-edition:9.11`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install mattermost
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
