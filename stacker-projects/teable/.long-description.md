## Teable

A self-hosted Teable stack, ready to deploy with Stacker.

### What's included

- **Db** (db)
- **Redis** (redis)

### Docker images

- `ghcr.io/teableio/teable:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install teable
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
