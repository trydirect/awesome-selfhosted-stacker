## Onetimesecret

A self-hosted Onetimesecret stack, ready to deploy with Stacker.

### What's included

- **Onetimesecret Redis** (onetimesecret-redis)

### Docker images

- `onetimesecret/onetimesecret:latest`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install onetimesecret
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
