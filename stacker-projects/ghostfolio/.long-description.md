## Ghostfolio

A self-hosted Ghostfolio stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `ghostfolio/ghostfolio:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install ghostfolio
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
