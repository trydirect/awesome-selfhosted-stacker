## Bookstack

A self-hosted Bookstack stack, ready to deploy with Stacker.

### What's included

- **Bookstack Db** (bookstack-db)

### Docker images

- `lscr.io/linuxserver/bookstack:24.10.20241021`
- `lscr.io/linuxserver/mariadb:11.4`

### Quick start

```bash
stacker install bookstack
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
