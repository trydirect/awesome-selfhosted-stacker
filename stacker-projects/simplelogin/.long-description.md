## Simplelogin

A self-hosted Simplelogin stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `simplelogin/app:4.24.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install simplelogin
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
