## Outline

A self-hosted Outline stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `outlinewiki/outline:latest`
- `postgres:16`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install outline
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
