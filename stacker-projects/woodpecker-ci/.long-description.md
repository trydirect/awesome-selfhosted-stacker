## Woodpecker Ci

A self-hosted Woodpecker Ci stack, ready to deploy with Stacker.

### What's included

- **Woodpecker Agent** (woodpecker-agent)

### Docker images

- `woodpeckerci/woodpecker-server:v2.7.0`
- `woodpeckerci/woodpecker-agent:v2.7.0`

### Quick start

```bash
stacker install woodpecker-ci
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
