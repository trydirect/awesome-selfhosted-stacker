## Rag As A Service

A self-hosted Rag As A Service stack, ready to deploy with Stacker.

### Docker images

- `optimum/rag-as-a-service:1.0.0`

### Quick start

```bash
stacker install rag-as-a-service
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
