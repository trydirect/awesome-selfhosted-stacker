## Kestra

A self-hosted Kestra stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `kestra/kestra:v0.19.8`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install kestra
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
