## Apache Airflow

A self-hosted Apache Airflow stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `apache/airflow:2.10.2`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install apache-airflow
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
