## Redash

A self-hosted Redash stack, ready to deploy with Stacker.

### What's included

- **Redash Db** (redash_db)
- **Redis** (redis)

### Docker images

- `redash/redash:10.1.0`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install redash
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
