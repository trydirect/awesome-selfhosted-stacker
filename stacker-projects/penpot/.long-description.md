## Penpot

A self-hosted Penpot stack, ready to deploy with Stacker.

### What's included

- **Penpot Backend** (penpot-backend)
- **Penpot Exporter** (penpot-exporter)
- **Postgres** (postgres)
- **Redis** (redis)
- **Mailcatcher** (mailcatcher)

### Docker images

- `penpotapp/frontend:latest`
- `penpotapp/backend:latest`
- `penpotapp/exporter:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`
- `sj26/mailcatcher:0.9.0`

### Quick start

```bash
stacker install penpot
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
