## Firezone

A self-hosted Firezone stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `firezone/firezone:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install firezone
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
