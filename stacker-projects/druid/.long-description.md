## Druid

A self-hosted Druid stack, ready to deploy with Stacker.

### Docker images

- `apache/druid:31.0.0`
- `postgres:17.6`
- `zookeeper:3.5.10`
- `apache/druid:31.0.0`
- `apache/druid:31.0.0`
- `apache/druid:31.0.0`

### Quick start

```bash
stacker install druid
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
