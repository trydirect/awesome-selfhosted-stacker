## Standard Notes

A self-hosted Standard Notes stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)
- **Cache** (cache)

### Docker images

- `standardnotes/server:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install standard-notes
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
