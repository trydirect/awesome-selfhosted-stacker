## Statistics For Strava

A self-hosted Statistics For Strava stack, ready to deploy with Stacker.

### Docker images

- `robiningelbrecht/strava-statistics:latest`
- `robiningelbrecht/strava-statistics:latest`

### Quick start

```bash
stacker install statistics-for-strava
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
