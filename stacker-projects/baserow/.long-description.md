## Baserow

A self-hosted Baserow stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `baserow/baserow:2.4.1`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install baserow
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
