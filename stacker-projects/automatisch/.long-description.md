## Automatisch

A self-hosted Automatisch stack, ready to deploy with Stacker.

### What's included

- **Automatisch Db** (automatisch-db)
- **Redis** (redis)

### Docker images

- `trydirect/automatisch:0.4.0`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install automatisch
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
