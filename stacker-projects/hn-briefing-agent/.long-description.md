## Hn Briefing Agent

A self-hosted Hn Briefing Agent stack, ready to deploy with Stacker.

### Docker images

- `optimum/hn-briefing-agent:1.0.0`

### Quick start

```bash
stacker install hn-briefing-agent
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
