## Evolution Api

A self-hosted Evolution Api stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `evoapicloud/evolution-api:v2.3.7`
- `postgres:15.8-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install evolution-api
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
