## Wallabag

A self-hosted Wallabag stack, ready to deploy with Stacker.

### What's included

- **Wallabag Db** (wallabag_db)
- **Redis** (redis)

### Docker images

- `wallabag/wallabag:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install wallabag
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
