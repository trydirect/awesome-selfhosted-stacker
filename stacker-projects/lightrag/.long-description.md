## Lightrag

A self-hosted Lightrag stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Qdrant** (qdrant)

### Docker images

- `ghcr.io/hkuds/lightrag:v1.5.7`
- `postgres:16.4-alpine`
- `qdrant/qdrant:v1.19.2`

### Quick start

```bash
stacker install lightrag
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
