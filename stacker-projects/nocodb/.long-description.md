## Nocodb

A self-hosted Nocodb stack, ready to deploy with Stacker.

### What's included

- **Nocodb Db** (nocodb-db)

### Docker images

- `nocodb/nocodb:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install nocodb
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
