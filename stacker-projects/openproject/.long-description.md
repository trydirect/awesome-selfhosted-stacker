## Openproject

A self-hosted Openproject stack, ready to deploy with Stacker.

### What's included

- **Openproject Worker** (openproject-worker)
- **Postgres** (postgres)
- **Mailcatcher** (mailcatcher)

### Docker images

- `openproject/openproject:16`
- `openproject/openproject:16`
- `postgres:16.4-alpine`
- `sj26/mailcatcher:0.9.0`

### Quick start

```bash
stacker install openproject
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
