## Easyappointments

A self-hosted Easyappointments stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `alextselegidis/easyappointments:1.5.0`
- `mysql:8.4.4`

### Quick start

```bash
stacker install easyappointments
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
