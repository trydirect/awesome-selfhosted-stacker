## Open Notebook

A self-hosted Open Notebook stack, ready to deploy with Stacker.

### What's included

- **Surrealdb** (surrealdb)

### Docker images

- `lfnovo/open_notebook:1.15.0`
- `surrealdb/surrealdb:v2`

### Quick start

```bash
stacker install open-notebook
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
