## Focalboard

A self-hosted Focalboard stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `mattermost/focalboard:7.11.4`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install focalboard
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
