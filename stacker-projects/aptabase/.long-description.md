## Aptabase

A self-hosted Aptabase stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Clickhouse** (clickhouse)

### Docker images

- `ghcr.io/aptabase/aptabase:main`
- `postgres:16.4-alpine`
- `clickhouse/clickhouse-server:23.8.4.69`

### Quick start

```bash
stacker install aptabase
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
