## Dify

A self-hosted Dify stack, ready to deploy with Stacker.

### What's included

- **Api** (api)
- **Db** (db)
- **Redis** (redis)

### Docker images

- `langgenius/dify-web:latest`
- `langgenius/dify-api:latest`
- `postgres:15`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install dify
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
