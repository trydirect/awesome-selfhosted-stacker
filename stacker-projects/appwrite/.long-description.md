## Appwrite

A self-hosted Appwrite stack, ready to deploy with Stacker.

### What's included

- **Mariadb** (mariadb)
- **Redis** (redis)
- **Influxdb** (influxdb)

### Docker images

- `appwrite/appwrite:1.6.0`
- `mariadb:11.4`
- `redis:7.4-alpine`
- `influxdb:1.8`

### Quick start

```bash
stacker install appwrite
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
