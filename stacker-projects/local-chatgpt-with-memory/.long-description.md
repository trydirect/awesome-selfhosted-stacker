## Local Chatgpt With Memory

A self-hosted Local Chatgpt With Memory stack, ready to deploy with Stacker.

### What's included

- **Qdrant** (qdrant)
- **Ollama** (ollama)

### Docker images

- `optimum/local-chatgpt-with-memory:1.0.0`
- `qdrant/qdrant:v1.19.2`
- `ollama/ollama:0.40.5`

### Quick start

```bash
stacker install local-chatgpt-with-memory
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
