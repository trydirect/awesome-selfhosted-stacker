## Hanko

A self-hosted Hanko stack, ready to deploy with Stacker.

### What's included

- **Hanko Db** (hanko-db)

### Docker images

- `ghcr.io/teamhanko/hanko:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install hanko
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
