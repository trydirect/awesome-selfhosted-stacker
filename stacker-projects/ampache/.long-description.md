## Ampache

A self-hosted Ampache stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `ampache/ampache:6.4.2`
- `mysql:8.4.4`

### Quick start

```bash
stacker install ampache
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
