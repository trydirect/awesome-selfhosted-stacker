# Dashy

**Self-hosted dashboard** — highly customizable dashboard with widgets.

### Authentication & Security

This service requires authentication to access. Configure strong passwords or enable SSO/OAuth before exposing to the internet. Use HTTPS/TLS for all traffic.


## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/dashy

# Deploy
stacker deploy --target cloud --key htz-0
```

| Service | Port | Description |
