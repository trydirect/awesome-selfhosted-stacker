## Kimai

A self-hosted Kimai stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `kimai/kimai2:2.71.0`
- `mysql:8.4.4`

### Quick start

```bash
stacker install kimai
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
