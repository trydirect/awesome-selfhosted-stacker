## S4Core

A self-hosted S4Core stack, ready to deploy with Stacker.

### What's included

- **S4Console** (s4console)

### Docker images

- `s4core/s4core:0.1.0`
- `s4core/s4console:0.1.0`

### Quick start

```bash
stacker install s4core
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
