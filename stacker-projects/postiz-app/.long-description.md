## Postiz App

A self-hosted Postiz App stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/gitroomhq/postiz-app:latest`
- `postgres:17.0-alpine`
- `redis:7.2`
- `elasticsearch:7.17.27`
- `postgres:16`
- `temporalio/auto-setup:1.28.1`

### Quick start

```bash
stacker install postiz-app
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
