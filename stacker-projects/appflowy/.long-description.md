## Appflowy

A self-hosted Appflowy stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `appflowyinc/appflowy_cloud:0.8.1`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install appflowy
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
