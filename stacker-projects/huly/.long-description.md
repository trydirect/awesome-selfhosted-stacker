## Huly

A self-hosted Huly stack, ready to deploy with Stacker.

### What's included

- **Huly Account** (huly-account)
- **Huly Worker** (huly-worker)
- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `ghcr.io/hcengineering/platform:v0.6.0`
- `ghcr.io/hcengineering/account:v0.6.0`
- `ghcr.io/hcengineering/worker:v0.6.0`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install huly
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
