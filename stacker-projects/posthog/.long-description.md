## Posthog

A self-hosted Posthog stack, ready to deploy with Stacker.

### What's included

- **Posthog Db** (posthog_db)
- **Redis** (redis)

### Docker images

- `posthog/posthog:latest`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install posthog
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
