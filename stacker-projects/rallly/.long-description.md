## Rallly

A self-hosted Rallly stack, ready to deploy with Stacker.

### What's included

- **Rallly Db** (rallly-db)

### Docker images

- `lukevella/rallly:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install rallly
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
