## Audiobookshelf

A self-hosted Audiobookshelf stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/advplyr/audiobookshelf:latest`

### Quick start

```bash
stacker install audiobookshelf
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
