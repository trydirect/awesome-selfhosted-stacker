## Zulip

A self-hosted Zulip stack, ready to deploy with Stacker.

### What's included

- **Zulip Db** (zulip_db)

### Docker images

- `zulip/docker-zulip:latest`
- `zulip/zulip-postgresql:latest`

### Quick start

```bash
stacker install zulip
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
