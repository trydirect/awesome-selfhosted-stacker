## Infisical

A self-hosted Infisical stack, ready to deploy with Stacker.

### What's included

- **Infisical Redis** (infisical-redis)
- **Infisical Db** (infisical-db)

### Docker images

- `infisical/infisical:v0.162.9`
- `redis:7.4-alpine`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install infisical
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
