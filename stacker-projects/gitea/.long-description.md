## Gitea

A self-hosted Gitea stack, ready to deploy with Stacker.

### What's included

- **Gitea Db** (gitea_db)

### Docker images

- `gitea/gitea:1.22.3`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install gitea
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
