## Passbolt

A self-hosted Passbolt stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Mailcatcher** (mailcatcher)

### Docker images

- `passbolt/passbolt:4.8.0`
- `mariadb:11.4`
- `sj26/mailcatcher:0.9.0`

### Quick start

```bash
stacker install passbolt
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
