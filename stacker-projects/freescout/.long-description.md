## Freescout

A self-hosted Freescout stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `bfren/freescout:latest`
- `mysql:8.4.4.0`

### Quick start

```bash
stacker install freescout
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
