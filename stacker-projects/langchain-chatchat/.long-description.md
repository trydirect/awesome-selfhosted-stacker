## Langchain Chatchat

A self-hosted Langchain Chatchat stack, ready to deploy with Stacker.

### What's included

- **Xinference** (xinference)

### Docker images

- `chatimage/chatchat:0.3.1.3-93e2c87-20240829`
- `xprobe/xinference:v0.12.3-cpu`

### Quick start

```bash
stacker install langchain-chatchat
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
