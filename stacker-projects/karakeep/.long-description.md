## Karakeep

A self-hosted Karakeep stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Meilisearch** (meilisearch)

### Docker images

- `ghcr.io/karakeep-app/karakeep:v0.40.3`
- `postgres:16.4-alpine`
- `getmeili/meilisearch:v1.11`

### Quick start

```bash
stacker install karakeep
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
