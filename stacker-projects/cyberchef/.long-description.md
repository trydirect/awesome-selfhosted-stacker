## Cyberchef

A self-hosted Cyberchef stack, ready to deploy with Stacker.

### Docker images

- `ghcr.io/gchq/cyberchef:v10.18.8`

### Quick start

```bash
stacker install cyberchef
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
