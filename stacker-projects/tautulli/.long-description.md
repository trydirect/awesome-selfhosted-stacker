## Tautulli

A self-hosted Tautulli stack, ready to deploy with Stacker.

### Docker images

- `lscr.io/linuxserver/tautulli:2.4.6`

### Quick start

```bash
stacker install tautulli
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
