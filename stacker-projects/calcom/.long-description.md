## Calcom

A self-hosted Calcom stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `calcom/cal.com:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install calcom
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
