## Bunkerweb

A self-hosted Bunkerweb stack, ready to deploy with Stacker.

### What's included

- **Redis** (redis)

### Docker images

- `bunkerity/bunkerweb:1.5.13`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install bunkerweb
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
