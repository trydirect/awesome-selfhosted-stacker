# Pingvin Share

**Self-hosted file sharing** — WeTransfer alternative with no file size limits.

## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/pingvin-share

# Deploy
stacker deploy --target cloud --key htz-0
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| Pingvin Share | 3000 | File sharing UI |
