## Budibase

A self-hosted Budibase stack, ready to deploy with Stacker.

### What's included

- **Couchdb** (couchdb)
- **Redis** (redis)
- **Minio** (minio)

### Docker images

- `budibase/budibase:v3.1.1`
- `couchdb:3`
- `redis:7.4-alpine`
- `firstfinger/minio:latest`

### Quick start

```bash
stacker install budibase
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
