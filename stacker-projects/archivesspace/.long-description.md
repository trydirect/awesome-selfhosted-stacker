## Archivesspace

A self-hosted Archivesspace stack, ready to deploy with Stacker.

### What's included

- **Db** (db)
- **Solr** (solr)

### Docker images

- `archivesspace/archivesspace:3.5.1`
- `mysql:8.4`
- `archivesspace/solr:3.5.1`

### Quick start

```bash
stacker install archivesspace
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
