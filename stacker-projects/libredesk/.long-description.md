## Libredesk

A self-hosted Libredesk stack, ready to deploy with Stacker.

### What's included

- **Db** (db)
- **Redis** (redis)

### Docker images

- `libredesk/libredesk:v2.9.0`
- `postgres:17.0-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install libredesk
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
