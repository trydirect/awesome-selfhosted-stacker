## Plausible

A self-hosted Plausible stack, ready to deploy with Stacker.

### What's included

- **Plausible Db** (plausible_db)
- **Plausible Events Db** (plausible_events_db)

### Docker images

- `ghcr.io/plausible/community-edition:v3.2.1`
- `postgres:16.4-alpine`
- `clickhouse/clickhouse-server:24.12-alpine`

### Quick start

```bash
stacker install plausible
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
