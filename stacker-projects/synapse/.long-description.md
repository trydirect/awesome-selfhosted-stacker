## Synapse

A self-hosted Synapse stack, ready to deploy with Stacker.

### What's included

- **Synapse Db** (synapse_db)

### Docker images

- `matrixdotorg/synapse:v1.128.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install synapse
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
