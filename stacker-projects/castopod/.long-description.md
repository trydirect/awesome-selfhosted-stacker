## Castopod

A self-hosted Castopod stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `castopod/app:1.6.4`
- `mysql:8.4.4`

### Quick start

```bash
stacker install castopod
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
