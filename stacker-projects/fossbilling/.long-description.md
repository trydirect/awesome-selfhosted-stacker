## Fossbilling

A self-hosted Fossbilling stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `fossbilling/fossbilling:latest`
- `mariadb:11.4`

### Quick start

```bash
stacker install fossbilling
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
