## Strapi

A self-hosted Strapi stack, ready to deploy with Stacker.

### What's included

- **Strapi Db** (strapi_db)

### Docker images

- `naskio/strapi:4.25.9`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install strapi
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
