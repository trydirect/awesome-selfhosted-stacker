## Keycloak

A self-hosted Keycloak stack, ready to deploy with Stacker.

### What's included

- **Keycloak Db** (keycloak-db)

### Docker images

- `quay.io/keycloak/keycloak:26.0.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install keycloak
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
