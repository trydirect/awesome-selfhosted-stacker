# Grist

**Self-hosted spreadsheet-database hybrid** — relational spreadsheet with Python formulas.

## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/grist

# Deploy
stacker deploy --target cloud --key htz-0
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| Grist | 8484 | Spreadsheet UI |
