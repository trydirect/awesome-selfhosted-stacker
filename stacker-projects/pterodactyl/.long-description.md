## Pterodactyl

A self-hosted Pterodactyl stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)
- **Redis** (redis)

### Docker images

- `ghcr.io/pterodactyl/panel:latest`
- `mysql:8.4.4`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install pterodactyl
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
