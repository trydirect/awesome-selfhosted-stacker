## Funkwhale

A self-hosted Funkwhale stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `funkwhale/all-in-one:1.2.10`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install funkwhale
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
