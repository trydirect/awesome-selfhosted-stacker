## Mastodon

Self-hosted, federated social network built on ActivityPub. Mastodon lets you run your own microblogging server with full control over moderation, data, and community rules.

### What's included

- **Mastodon** - web interface, API, and ActivityPub federation
- **Sidekiq** - background job processing for email, media, and federation
- **PostgreSQL** - primary database for accounts, posts, and relationships
- **Redis** - caching, sessions, and Sidekiq job queue

### Key features

- **Federation** - connect to the entire Fediverse (Mastodon, Pleroma, Pixelfed, etc.)
- **Moderation tools** - content filtering, user blocking, instance-level controls
- **Custom branding** - logos, colors, and about pages
- **Media handling** - image/video uploads with S3-compatible storage support
- **API-first** - REST API + WebSocket streaming for third-party clients

### Quick start

```bash
stacker install mastodon
```

### Configuration

Set `LOCAL_DOMAIN` and `SECRET_KEY_BASE` in `.env` before deploying. Admin account is created on first boot - check the server logs for the initial password reset link.
