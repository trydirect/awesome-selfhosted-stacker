## Mastodon

A self-hosted Mastodon stack, ready to deploy with Stacker.

### What's included

- **Mastodon Db** (mastodon_db)
- **Redis** (redis)
- **Sidekiq** (sidekiq)

### Docker images

- `ghcr.io/mastodon/mastodon:v4.3.2`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`
- `ghcr.io/mastodon/mastodon:v4.3.2`

### Quick start

```bash
stacker install mastodon
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
