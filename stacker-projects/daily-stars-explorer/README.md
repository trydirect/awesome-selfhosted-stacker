# Daily Stars Explorer

**Self-hosted astronomy tool** — track daily GitHub stars trends.

## Deploy with Stacker

```bash
git clone https://github.com/trydirect/awesome-selfhosted-stacker.git
cd awesome-selfhosted-stacker/stacker-projects/daily-stars-explorer

# Deploy
stacker deploy --target cloud --key htz-0
```

## Services

| Service | Port | Description |
|---------|------|-------------|
| Daily Stars Explorer | 8080 | Stars tracker UI |
