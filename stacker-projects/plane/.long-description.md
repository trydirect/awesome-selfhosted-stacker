## Plane

A self-hosted Plane stack, ready to deploy with Stacker.

### What's included

- **Db** (db)
- **Redis** (redis)
- **Mq** (mq)
- **Minio** (minio)

### Docker images

- `makeplane/plane-aio-community:v1.4.2`
- `postgres:15.8-alpine`
- `redis:7.4-alpine`
- `rabbitmq:3.13-alpine`
- `bitnamilegacy/minio:2024.10.13`

### Quick start

```bash
stacker install plane
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
