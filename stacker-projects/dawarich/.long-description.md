## Dawarich

A self-hosted Dawarich stack, ready to deploy with Stacker.

### What's included

- **Dawarich Background** (dawarich-background)
- **Postgres** (postgres)
- **Redis** (redis)

### Docker images

- `freikin/dawarich:0.16.0`
- `freikin/dawarich:0.16.0`
- `postgres:16.4-alpine`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install dawarich
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
