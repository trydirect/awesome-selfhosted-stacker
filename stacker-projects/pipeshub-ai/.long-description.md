## Pipeshub Ai

A self-hosted Pipeshub Ai stack, ready to deploy with Stacker.

### What's included

- **Mongodb** (mongodb)
- **Redis** (redis)
- **Qdrant** (qdrant)
- **Neo4J** (neo4j)

### Docker images

- `pipeshubai/pipeshub-ai:0.10.0`
- `mongo:8.0`
- `redis:7.4.1-bookworm`
- `qdrant/qdrant:v1.15`
- `neo4j:5.26.0`

### Quick start

```bash
stacker install pipeshub-ai
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
