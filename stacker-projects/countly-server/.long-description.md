## Countly Server

A self-hosted Countly Server stack, ready to deploy with Stacker.

### What's included

- **Mongodb** (mongodb)
- **Countly Api** (countly-api)
- **Countly Frontend** (countly-frontend)

### Docker images

- `bitnami/nginx:latest`
- `bitnami/mongodb:latest`
- `countly/api:latest`
- `countly/frontend:latest`

### Quick start

```bash
stacker install countly-server
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
