## Khoj

A self-hosted Khoj stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `ghcr.io/khoj-ai/khoj:v1.28.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install khoj
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
