## Localagi

A self-hosted Localagi stack, ready to deploy with Stacker.

### What's included

- **Localai** (localai)
- **Postgres** (postgres)

### Docker images

- `quay.io/mudler/localagi:1.0.0`
- `localai/localai:v2.29.0`
- `quay.io/mudler/localrecall:v0.5.2-postgresql`

### Quick start

```bash
stacker install localagi
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
