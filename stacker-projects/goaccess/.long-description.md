## Goaccess

A self-hosted Goaccess stack, ready to deploy with Stacker.

### What's included

- **Goaccess** (goaccess)

### Docker images

- `nginx:1.27-alpine`
- `allinurl/goaccess:latest`

### Quick start

```bash
stacker install goaccess
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
