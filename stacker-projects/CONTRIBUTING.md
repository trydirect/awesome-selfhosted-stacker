# Contributing

One app per pull request. Keep reviews fast.

## Add a new app

### 1. Create the directory

```bash
mkdir my-app && cd my-app
```

### 2. Create `stacker.yml`

Follow this template:

```yaml
name: my-app
version: "1.0.0"

project:
  identity: my-app

install:
  inputs:
    commonDomain: my-app.example.com

app:
  type: custom
  image: org/my-app:latest    # pin a version, avoid :latest
  ports:
    - "8080:8080"              # host:container
  environment:
    MY_VAR: "${MY_VAR}"        # reference secrets from .env
  volumes:
    - myapp_data:/data

# Only if the app needs a database:
services:
  - name: postgres
    image: postgres:16-alpine
    ports:
      - "127.0.0.1:5432:5432"  # bind to localhost
    environment:
      POSTGRES_DB: myapp
      POSTGRES_USER: myapp
      POSTGRES_PASSWORD: "${DB_PASSWORD}"
    volumes:
      - myapp_pgdata:/var/lib/postgresql/data
    healthcheck:
      test: pg_isready -U myapp
      interval: 10s
      timeout: 5s
      retries: 5

proxy:
  type: none
  auto_detect: false

deploy:
  target: local
  cloud:
    provider: hetzner
    region: fsn1
    size: cpx22
    public_ports:
      - "8080"

# Only if the app has secrets:
config_contract:
  app:
    environment:
      - name: DB_PASSWORD
        required: true
        secret: true

hooks:
  pre_build: ./scripts/generate-secrets.sh

monitoring:
  status_panel: true

env_file: .env

volumes:
  myapp_data: {}
  myapp_pgdata: {}
```

### 3. Create `.env.example`

```bash
# Stacker project configuration
# This file is committed to git. Actual secrets go in .env (gitignored).

# Common domain (update for production)
COMMON_DOMAIN=example.com

# Database password (auto-generated by generate-secrets.sh)
DB_PASSWORD=
```

### 4. Create `.gitignore`

```bash
# Secrets
.env
.env.local
.env.production

# Stacker generated files
.stacker/

# Docker
docker-compose.override.yml

# OS
.DS_Store
Thumbs.db
```

### 5. Create `scripts/generate-secrets.sh`

Only needed if the app has secrets. Skip for simple apps with no `${...}` vars.

```bash
#!/bin/bash
set -e
ENV_FILE=".env"

generate_if_empty() {
  local key="$1"
  local value
  value=$(openssl rand -hex 32)
  if grep -q "^${key}=" "$ENV_FILE" 2>/dev/null; then
    local existing
    existing=$(grep "^${key}=" "$ENV_FILE" | cut -d'=' -f2-)
    if [ -n "$existing" ] && [ "$existing" != "" ]; then
      return
    fi
  fi
  if grep -q "^${key}=" "$ENV_FILE" 2>/dev/null; then
    sed -i '' "s|^${key}=.*|${key}=${value}|" "$ENV_FILE"
  else
    echo "${key}=${value}" >> "$ENV_FILE"
  fi
  echo "Generated: ${key}"
}

generate_if_empty "DB_PASSWORD"
generate_if_empty "SECRET_KEY"
```

Make it executable: `chmod +x scripts/generate-secrets.sh`

### 6. Test locally

```bash
./scripts/generate-secrets.sh
stacker config validate
stacker deploy
curl -s -o /dev/null -w "%{http_code}" http://localhost:8080
```

### 7. Test on server

```bash
stacker deploy --target server --force-rebuild
curl -s -o /dev/null -w "%{http_code}" http://SERVER_IP:8080
```

### 8. Update `stacker-projects/INDEX.md`

Add a row to the correct category table.

## Conventions

- **Pin image tags** — use specific versions (`postgres:16-alpine`), not `:latest`
- **Bind DB ports to localhost** — `"127.0.0.1:5432:5432"` prevents external access
- **Use named volumes** — `volume_name:/path` for persistence
- **Health checks on databases** — `pg_isready`, `mysqladmin ping`, etc.
- **No secrets in stacker.yml** — reference `${VAR}` and populate via `.env`
- **No comments in stacker.yml** — keep it clean (serde_yaml 0.9 quoting bug)

## File checklist

Required for every project:

- [ ] `stacker.yml`
- [ ] `.env.example`
- [ ] `.gitignore`

Required only if the app has secrets:

- [ ] `scripts/generate-secrets.sh` (executable)
- [ ] `hooks.pre_build` pointing to the script
- [ ] `config_contract` declaring the secrets

Optional:

- [ ] `Dockerfile` (if the image needs customization)
- [ ] `README.md` (3-5 lines: what it is, default port, gotchas)
