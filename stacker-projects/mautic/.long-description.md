## Mautic

A self-hosted Mautic stack, ready to deploy with Stacker.

### What's included

- **Db** (db)
- **Worker** (worker)
- **Cron** (cron)

### Docker images

- `mautic/mautic:6.0.6-apache`
- `mysql:8.4`
- `mautic/mautic:6.0.6-apache`
- `mautic/mautic:6.0.6-apache`

### Quick start

```bash
stacker install mautic
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
