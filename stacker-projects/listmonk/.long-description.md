## Listmonk

A self-hosted Listmonk stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)

### Docker images

- `listmonk/listmonk:latest`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install listmonk
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
