## Anycable

A self-hosted Anycable stack, ready to deploy with Stacker.

### What's included

- **Redis** (redis)

### Docker images

- `anycable/anycable-go:1.4.4`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install anycable
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
