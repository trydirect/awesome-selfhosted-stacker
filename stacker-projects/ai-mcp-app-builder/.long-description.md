## Ai Mcp App Builder

A self-hosted Ai Mcp App Builder stack, ready to deploy with Stacker.

### Docker images

- `optimum/ai-mcp-app-builder:1.0.0`

### Quick start

```bash
stacker install ai-mcp-app-builder
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
