## Espocrm

A self-hosted Espocrm stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `espocrm/espocrm:latest`
- `mysql:8.4.4`

### Quick start

```bash
stacker install espocrm
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
