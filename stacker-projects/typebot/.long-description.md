## Typebot

A self-hosted Typebot stack, ready to deploy with Stacker.

### What's included

- **Typebot Db** (typebot-db)

### Docker images

- `baptistearno/typebot-builder:3.19.1`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install typebot
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
