## Librebooking

A self-hosted Librebooking stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `librebooking/librebooking:7.1.0`
- `mysql:8.4.4`

### Quick start

```bash
stacker install librebooking
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
