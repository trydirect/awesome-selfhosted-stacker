## Mail Archiver

A self-hosted Mail Archiver stack, ready to deploy with Stacker.

### Docker images

- `s1t5/mailarchiver:latest`
- `postgres:17.0-alpine`

### Quick start

```bash
stacker install mail-archiver
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
