## Seafile

A self-hosted Seafile stack, ready to deploy with Stacker.

### What's included

- **Mysql** (mysql)

### Docker images

- `seafileltd/seafile-mc:13.0.25`
- `mysql:8.4.4`

### Quick start

```bash
stacker install seafile
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
