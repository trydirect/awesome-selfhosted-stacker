## Self Hosted Ai Starter Kit

A self-hosted Self Hosted Ai Starter Kit stack, ready to deploy with Stacker.

### What's included

- **Postgres** (postgres)
- **Ollama** (ollama)
- **Qdrant** (qdrant)

### Docker images

- `n8nio/n8n:2.43.6`
- `postgres:16.4-alpine`
- `ollama/ollama:0.40.5`
- `qdrant/qdrant:v1.19.2`

### Quick start

```bash
stacker install self-hosted-ai-starter-kit
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
