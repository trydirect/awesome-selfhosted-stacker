## Invoiceninja

A self-hosted Invoiceninja stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `invoiceninja/invoiceninja:latest`
- `mariadb:11.4`

### Quick start

```bash
stacker install invoiceninja
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
