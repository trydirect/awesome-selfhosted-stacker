## Openagent

A self-hosted Openagent stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `casbin/openagent:2.95.1`
- `mysql:8.4.43`

### Quick start

```bash
stacker install openagent
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
