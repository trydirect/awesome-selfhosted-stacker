## Discourse

A self-hosted Discourse stack, ready to deploy with Stacker.

### What's included

- **Discourse Db** (discourse_db)
- **Redis** (redis)

### Docker images

- `discourse/discourse:2026.10.0-latest.1`
- `pgvector/pgvector:0.8.0-pg16`
- `redis:7.4-alpine`

### Quick start

```bash
stacker install discourse
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
