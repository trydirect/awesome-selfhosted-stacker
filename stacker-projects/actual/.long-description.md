## Actual

A self-hosted Actual stack, ready to deploy with Stacker.

### What's included

- **Db** (db)

### Docker images

- `actualbudget/actual-server:24.10.0`
- `postgres:16.4-alpine`

### Quick start

```bash
stacker install actual
```

### Configuration

Secrets and passwords are auto-generated on first deploy. Customize via `stacker.yml` or environment variables.
